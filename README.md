# Upper Limb Anatomy — Interactive Study Site

An interactive revision site for medical students covering the upper limb anatomy block:

1. Back, Shoulder & Scapular Regions
2. The Axilla & Brachial Plexus
3. The Arm & Cubital Fossa
4. Anterior Forearm
5. Posterior Forearm
6. The Hand

Static site (HTML/CSS/JS, no build step), deployed with GitHub Pages.
